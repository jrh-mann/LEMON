UI Design

Design Principles

Real-time Feedback

The canvas updates in real time as the LLM builds the workflow. Users see nodes and connections appear as tool calls execute, giving immediate visual confirmation of progress without needing to wait for a response to complete.

Direct Manipulation

Users can drag nodes to reposition them, draw connections by clicking and dragging between nodes, and right-click for context menus. The canvas is not a passive display but an interactive surface that responds to user input.

Visibility of System State

The chat panel shows streaming LLM responses and lists each tool call as it executes. During stepped execution, the active node is highlighted on the canvas with the execution path traced, so users always know what the system is doing.

Simplicity

The primary interface is a chat window. Users describe what they want in plain language and the system handles the rest. The canvas and sidebar provide visual feedback but the core interaction model stays conversational.

Tolerance

Users can undo and redo canvas operations, cancel in-progress LLM tasks, and the system handles reconnection after a page refresh. Mistakes are reversible, reducing the cost of experimentation.

Consistency

All node types follow the same visual language using colored shapes on the SVG canvas, and all editing follows the same pattern: either chat-based or direct manipulation. Users do not need to learn separate paradigms for different parts of the interface.
