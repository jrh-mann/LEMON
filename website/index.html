LEMON

Abstract

Clinical decision workflows are usually written up as static flowcharts, Word documents, or verbal explanations passed between colleagues. Turning these into something a computer can actually execute takes programming skills that most clinicians don't have, which makes the process slow, error-prone, and expensive.

LEMON lets doctors and other domain experts build executable decision workflows by chatting in plain English or uploading a photo of a flowchart. Behind the scenes, an LLM orchestrator translates what the user says into a structured decision tree on a visual canvas. The system handles six node types (start, process, decision, calculation, subprocess, end), typed variables, compound conditions, and nested subworkflows.

We built a working system with real-time streaming, a visual workflow editor, stepped execution that highlights the active path on the canvas, a workflow library that supports reusable packages as well as peer review and community voting, and export to JSON, Python, PNG, and bundle formats. We also developed an evaluation framework that scores how well the LLM extracts workflows across six dimensions. The project has over 1,300 automated tests and is deployed on Azure.
