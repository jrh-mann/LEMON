Abstract

Clinical decision workflows are typically recorded as static flowcharts, written protocols, or informal verbal descriptions. Converting these into structured, executable formats requires technical expertise that most clinicians do not have, making the process slow and error-prone.

LEMON is a web-based platform that allows domain experts to create executable decision workflows through natural language conversation or by uploading flowchart images. An LLM orchestrator interprets user input and builds structured decision trees on a visual canvas using a tool-use architecture. The system supports six node types (start, process, decision, calculation, subprocess, end), typed variables, compound conditions, and recursive subworkflows.

The team delivered a working system with real-time streaming, a visual workflow editor, stepped execution with live path highlighting, a workflow library, and export to JSON, Python, and PNG. An automated evaluation framework scores workflow extraction quality across six dimensions. The project includes over 1,200 automated tests and is deployed on Azure.
